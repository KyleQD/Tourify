# Tourify Seed Article Package

This package contains five publication-ready feature articles authored by **Tourify**.

## Included

1. Discovering music, artists, and live events
2. Artist EPK and connected analytics
3. Jobs, onboarding, workforce management, and live résumés
4. Tour and event operations
5. Marketplace listings and self-serve promotions

Each article includes:

- YAML front matter
- Excerpt and suggested category
- Local hero-image reference
- Photo alt text and attribution
- Credible sources and further reading
- Publication-ready Markdown body

`articles.seed.json` contains the same content in a structured format for database or CMS seeding.

## Important publishing note

Tourify is still evolving. Review navigation labels, feature availability, pricing, eligibility, and beta language against the current production build before publishing.
