Tourify hiring / onboarding / comms — smoke checklist and audit notes
======================================================================

E2E smoke (artist opportunity board)
------------------------------------
1. GET /api/artist-jobs/categories — returns rows; category ids match UI selects.
2. POST /api/artist-jobs (logged in) — creates row; 400 with clear message if category invalid.
3. GET /api/artist-jobs — new job appears when status=open.
4. POST /api/artist-jobs/{id}/applications (as another user) — row in artist_job_applications.
5. GET /api/artist-jobs/{id}/applications (as job owner) — lists applications.
6. PATCH application status (owner): pending → reviewed → accepted; applicant notification if configured.
