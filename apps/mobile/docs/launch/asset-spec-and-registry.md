# Launch Asset Spec and Registry

## Purpose

Define launch asset requirements, naming rules, and the current file registry for iOS and Android app launch.

## Asset Naming Convention

Use deterministic names so cache and review diffs are predictable:

`<asset-type>-<resolution>-v<version>.png`

Examples:
- `app-icon-1024-v1.png`
- `adaptive-foreground-1024-v1.png`
- `splash-image-1242x2436-v1.png`

Rules:
- Increase `vN` only when visual content changes
- Never overwrite old versions during a release cycle
- Update `app.config.ts` references only after final QA approval

## Current Registry

| Asset | Path | Required By | Spec |
| --- | --- | --- | --- |
| App icon | `assets/launch/app-icon-1024-v1.png` | iOS + Android | 1024x1024 PNG, no alpha for iOS final |
| Android adaptive foreground | `assets/launch/adaptive-foreground-1024-v1.png` | Android | Foreground glyph only |
| Splash image | `assets/launch/splash-image-1242x2436-v1.png` | iOS + Android | Center-safe composition on dark bg |
| iOS screenshot placeholder | `assets/launch/screenshot-ios-1290x2796-v1.png` | App Store Connect | 1290x2796 baseline placeholder |
| Android screenshot placeholder | `assets/launch/screenshot-android-1080x2400-v1.png` | Play Console | 1080x2400 baseline placeholder |

## Config Mapping

Mapped in `apps/mobile/app.config.ts`:

- `icon` -> `./assets/launch/app-icon-1024-v1.png`
- `splash.image` -> `./assets/launch/splash-image-1242x2436-v1.png`
- `android.adaptiveIcon.foregroundImage` -> `./assets/launch/adaptive-foreground-1024-v1.png`
- `android.adaptiveIcon.monochromeImage` -> `./assets/launch/adaptive-foreground-1024-v1.png`

## Design QA Gate

- Contrast passes WCAG AA against dark launch background
- Mark/logo remains legible at small sizes
- No text embedded in icon or splash
- iOS icon alpha channel removed before production
- Android adaptive icon foreground avoids edge clipping mask

## Regeneration Command

Placeholder assets are generated by:

```bash
python3 apps/mobile/scripts/generate-launch-placeholders.py
```

Replace placeholder files with final design exports using the same filenames, or bump version suffix and update `app.config.ts`.
