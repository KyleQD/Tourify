# Store Metadata Deck (iOS + Android)

## Usage

- Use this file as the source for App Store Connect and Google Play Console
- Keep `en-US` as canonical source copy
- Localized entries are launch-ready drafts and should pass native-speaker review before production submission

## Field Limits

### Apple App Store
- App Name: up to 30 chars
- Subtitle: up to 30 chars
- Promotional Text: up to 170 chars
- Keywords: up to 100 chars, comma-separated
- Description: up to 4000 chars
- What's New: up to 4000 chars

### Google Play
- App Name: up to 30 chars
- Short Description: up to 80 chars
- Full Description: up to 4000 chars
- Release Notes: per release entry

## Canonical Messaging Pillars

1. Discover local experiences with confidence
2. Book and manage plans in one place
3. Stay updated with realtime trip notifications
4. Move between traveler and creator workflows quickly
