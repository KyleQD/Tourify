# 14 - Definition Of Done

The Communications Command Center is done when:

- Logistics -> Comms opens without requiring a single event selection.
- Admins can view org/tour/event operational communications in one command surface.
- Existing Team Comms, DMs, event bulletins, event group chats, work inbox, notifications, and tasks still work.
- External email, weather, and WhatsApp are provider-gated and do not expose secrets to clients.
- Relays expose only approved excerpts to recipients.
- Acknowledgements show recipient status and cannot cross tenant boundaries.
- Communications can create tasks and schedule workflows using existing systems.
- Search/audit covers native and normalized operational events.
- RLS and route tests prove tenant isolation.
- Regression tests pass.
- Rollout docs and progress ledger reflect final state.
