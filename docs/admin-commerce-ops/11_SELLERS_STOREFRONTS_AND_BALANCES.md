# Sellers, Storefronts, and Balances

## Seller Profile

### Identity

- Account.
- Account type.
- Display name.
- Verification.
- Support status.

### Storefront

- Storefront state.
- Public URL.
- Listing count.
- Integration state.
- Last sync.

### Commerce Performance

- Gross sales.
- Net seller revenue.
- Refunds.
- Disputes.
- Fulfillment rate.
- Average fulfillment time.
- Customer cases.

### Balance

- Pending.
- Available.
- Held.
- Paid.
- Refunded.
- Disputed.
- Negative.

### Payout Readiness

- Provider account.
- Identity verification.
- Tax requirements.
- Bank or destination state.
- Supported currency.
- Restrictions.

### Restrictions

- None.
- Review.
- Listing restricted.
- Payout hold.
- Suspended.
- Closed.

## Seller Readiness States

- Not started.
- Storefront incomplete.
- Verification required.
- Payout setup required.
- Ready.
- Restricted.
- Suspended.

## Seller Issues

- Sales with no payout destination.
- Negative balance.
- Returned payout.
- High dispute rate.
- Repeated fulfillment failures.
- External integration disconnected.
- Verification expired.
- Prohibited listings.

## Seller Actions

- Contact.
- Add note.
- Request verification.
- Place or release payout hold.
- Hide listings.
- Suspend seller.
- Export statement.
- View settlement.
- View audit.

High-impact actions require reason and preview.

## Storefront Integrations

Track integrations such as external merchandise providers with:

- connection state,
- token health,
- last sync,
- imported listings,
- failed imports,
- ownership,
- disconnect history.
