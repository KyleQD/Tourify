# Master Implementation Roadmap

## Phase 0 — Discovery and Financial Safety Baseline

### Outcomes

- Complete commerce inventory.
- Provider map.
- Money movement diagrams.
- Authorization baseline.
- Reconciliation baseline.

### Exit Gate

Representative marketplace, ticketing, subscription, and promotion transactions are traceable end to end.

## Phase 1 — Commerce Context, Permissions, and Money Contracts

### Outcomes

- CommerceContext.
- Permission matrix.
- Currency-aware money type.
- API envelopes.
- Financial audit requirements.
- Cross-scope tests.

### Exit Gate

Every commerce request and action is safely scoped and money is represented consistently.

## Phase 2 — Canonical Domain and Read Models

### Outcomes

- Transaction source adapters.
- Party snapshots.
- Fee snapshots.
- Status dimensions.
- Secure read models.
- Integrity reports.

### Exit Gate

The UI can consume canonical commerce contracts without direct knowledge of fragmented source tables.

## Phase 3 — Commerce Overview and Attention Engine

### Outcomes

- Sales and liability KPIs.
- Needs Attention.
- Issue rules.
- Ownership and resolution.
- Drill-down.

### Exit Gate

Admins can identify financial and operational risk immediately.

## Phase 4 — Unified Transaction Ledger

### Outcomes

- Cross-source ledger.
- Search.
- Filters.
- Saved views.
- Exports.
- Detail drill-down.

### Exit Gate

Every commercial transaction is discoverable in one place.

## Phase 5 — Orders and Fulfillment

### Outcomes

- Order list redesign.
- Timeline.
- Party context.
- Fulfillment obligations.
- Support notes.
- Delivery queues.

### Exit Gate

Paid transactions remain visible until fulfilled or resolved.

### Outcomes

- Payment attempts.
- Provider events.
- Refund workflow.
- Chargeback queue.
- Case evidence.
- Approval thresholds.

### Exit Gate

Payment exceptions can be resolved safely and audibly.

### Outcomes

- Seller balance.
- Payout readiness.
