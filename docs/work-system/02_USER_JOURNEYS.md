# Worker Journeys

1. Discover an open job and submit an existing artist or staffing application.
2. Track that application, respond to an assignment invite, and see a confirmed assignment in Work Hub.
3. Review schedule, packets, location, and required acknowledgements before work.
4. Open the assignment-scoped Work Mode, follow updates, and record one server-confirmed check-in and check-out.
5. Review completed or cancelled work from Work Hub history without gaining access to employer-only records.
