# First Implementation Slice

The safest first slice is a **bilateral federation-readiness sandbox** with no representation, data pooling or collective action.

## Build

1. Audit the live Phase 9 organization and membership records.
2. Add separate federation entity and organization-application tables.
3. Add reserved powers and default-deny delegation policy.
4. Create a sandbox trust-framework version.
5. Issue one organization membership credential and one delegate credential.
6. Verify presentations through a private test route.
7. Implement suspension, revocation and key rotation.
8. Add a scoped mandate for service-directory administration only.
9. Publish signed service metadata to a non-public directory.
10. Run an organization withdrawal and credential revocation drill.

## Excluded

- creator-level federation membership;
- cross-border raw data transfer;
- public credential verification;
- global representation;
- collective licensing or bargaining;
- dues or benefit distribution;
- tokenized credentials or membership;
- automated external regulator or standards submissions.
