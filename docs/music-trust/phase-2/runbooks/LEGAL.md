# Rights Passport — Legal Runbook

## Scope

Counsel and legal administrators for Rights Passport disputes, training-reservation language, DMCA linkage, and court/arbitration orders. Tourify does not adjudicate ownership beyond published policy and evidence procedures.

## Intake

1. Capture dispute public ID, project ID, passport public ID, linked DMCA case ID (if any), and requesting counsel.
2. Keep DMCA takedown and passport-status actions **separately recorded** even when linked.
3. Do not request raw master audio or evidence signed URLs in email threads.

## Escalation paths

| Scenario | Action |
| --- | --- |
| Urgent court order | Freeze derivatives (`freeze_derivatives`), suspend public badge, preserve evidence, notify security |
| Active contributor dispute | Open structured dispute; block new passport issuance; optional playback preserve if policy-safe |
| Training-reservation challenge | Point to `/legal/music-training-reservation`; do not claim technical enforcement against scrapers |
| Compromised certificate | Revoke/suspend via admin review; rotate issuer keys per SECURITY runbook |

## Resolution types

Use only catalogued resolution types: unanimous amendment, replacement agreement, authority confirmation, registry correction, withdrawal, court order, admin metadata correction, legal escalation, dismissed.

## Appeals

Defined deadline, new evidence upload, separate reviewer where practical, reasoned decision, no retaliation. Public status must remain accurate during appeal.
