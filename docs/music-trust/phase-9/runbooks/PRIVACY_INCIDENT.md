# Runbook — Privacy Incident

## When
Suspected vault leakage, re-identification, or unauthorized research access.

## Actions
1. Execute `privacy_incident_stop`.
2. Suspend contribution licences and research projects under review.
3. Run `npm run music:creator-cooperative-outbox-worker`.
4. Preserve vault access logs; do not claim anonymization without assessment.
5. Escalate to privacy counsel before re-enable.
