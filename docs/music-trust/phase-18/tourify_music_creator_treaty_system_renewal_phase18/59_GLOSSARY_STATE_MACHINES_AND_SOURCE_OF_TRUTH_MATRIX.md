# Glossary, State Machines and Source-of-Truth Matrix

## Core terms

- **Renewal:** affirmative legal and governance action creating a new effective period after evidence and review.
- **Sunset:** scheduled end of authority or operation unless lawfully renewed.
- **Non-perpetuity:** no authority or institution continues merely because it existed previously or software remains available.
- **Intergenerational impact assessment:** structured analysis of long-term benefits, burdens, uncertainty, reversibility and lock-in.
- **Designated community:** the user community an archive must be able to serve with understandable preserved information.
- **Representation information:** information needed to interpret preserved data in the future.
- **Protocol archaeology:** preservation and replay of old schemas, definitions, implementations and test vectors.
- **Compensating action:** recorded action that reverses or mitigates an already executed transition when direct rollback is impossible.

## State separations

Renewal, extension, revival, replacement, suspension, termination, succession, dissolution and archival preservation are distinct. Public publication, operational deployment, legal effectiveness, external registration and historical archiving are distinct.

## Source-of-truth matrix

| Action | Controlling source |
|---|---|
| Music catalog identity | `artist_music` |
| Audio access | existing stream route and `resolveMusicAccess` |
| Copyright or rights status | current authoritative rights source and evidence |
| Licence authority | executed effective licence and mandate |
| Royalty position | Phase 3 ledger and official statements |
| Institutional competence | effective constitutive instrument |
| Participant authority | current competent-authority evidence |
| Renewal | effective instrument plus approved renewal decision |
| Privilege or immunity | current jurisdiction-specific legal instrument |
| Public projection | approved projection record and policy version |
| Archive authenticity | archival package, provenance, fixity and custody records |
| Succession | applicable legal instrument and current recognition decision |

Public identifiers, credentials, cached documents and search indexes are discovery aids, not high-impact authorization sources.
