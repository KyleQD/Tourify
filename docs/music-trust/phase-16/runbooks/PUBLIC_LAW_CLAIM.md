# Runbook: Public-Law Claim Stop

If UI/API/comms imply treaty, IO, privilege, UN, specialized-agency, or regulatory power without effective instruments:

1. Admin ops → `public_law_claim_stop` and `institution_freeze`.
2. Disable public registry / public-law service surfaces.
3. Publish correcting notice.
4. Preserve audit trail; open oversight case stub.
5. Do not re-enable until counsel + dual-control approval package.
