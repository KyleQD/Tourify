# First Implementation Slice

Implement only after the audit and required approvals:

1. Draft constitution/compact records and policy versions.
2. Two sandbox local organizations with explicit ratification instruments.
3. Reserved-power schedules and default-deny sovereignty checks.
4. Amendment classification, public comment and Formal Objection records.
5. Independent review sandbox with recusal and remedy.
6. Constitutional asset and operator schedules.
7. Tourify-unavailable, operator-replacement and legitimate-fork drills.

Do not enable irreversible asset transfer, universal identity, global mandates, collective action, tokenized governance or permanent emergency override.
