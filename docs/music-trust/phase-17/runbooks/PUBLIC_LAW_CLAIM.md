# Runbook: Public-Law Claim Stop

If UI/API/comms imply formal depositary, Article 102, privileges, assessed contributions, or collective authority without effective instruments:

1. Admin ops → `public_law_claim_stop` and `treaty_ops_freeze`.
2. Disable public registries / external activation surfaces.
3. Publish correcting notice.
4. Preserve audit trail; open compliance case stub.
