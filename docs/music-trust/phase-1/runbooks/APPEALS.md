# Music Trust Appeals Runbook

1. Accept an appeal from the affected track owner with the case/certificate public ID and a concise basis.
2. Create an immutable report event and preserve the original decision. Do not edit or erase a prior review.
3. Assign a reviewer who did not make the disputed decision when staffing permits.
4. Re-check the applicable standard version, declaration version, evidence integrity, contributor disclosures, and any new material.
5. Record one structured outcome: uphold, request information, reactivate, supersede, or revoke. Issue a new certificate version after material approved-track changes.
6. Send the artist-visible outcome and the next available escalation path. Never promise a legal conclusion.
