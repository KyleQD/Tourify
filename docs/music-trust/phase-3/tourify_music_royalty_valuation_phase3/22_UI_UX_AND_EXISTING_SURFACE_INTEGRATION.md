# UI/UX and Existing Surface Integration

## Artist navigation

Extend `/artist/music` rather than creating a second catalog:

- Catalog
- Earnings
- Statements
- Splits & Payees
- Valuation
- Financing Readiness

Each track/release workspace can add:

- Revenue
- Allocation
- Rights snapshot
- Valuation history
- Holds and disputes

## Principles

- show source quality and processing state;
- explain unmatched revenue and suspense;
- display gross, deductions, recoupment, holds, and net separately;
- never present an estimate as available cash;
- never present raw streams as money;
- show exact valuation date and model version;
- place investment features behind separate eligibility and partner gates;
- keep Jukebox playback unchanged.

## Existing surfaces

Artist profiles and EPKs may display opt-in high-level metrics or a verified catalog badge. Do not publicly expose private revenue, valuations, investor data, or participant splits by default.
