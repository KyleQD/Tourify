# Secondary Trading and Marketplace Boundary

Phase 3 does not build an open secondary market.

A user interface that facilitates transactions in crypto-asset securities can create broker-dealer, exchange, ATS, custody, transfer-agent, and recordkeeping questions. Tourify must not assume that calling a feature a bulletin board or peer-to-peer interface removes those requirements.

## Deferred capabilities

- order books;
- automated matching;
- bids and asks;
- market making;
- liquidity pools;
- instant token swaps;
- user-to-user settlement;
- public price charts implying liquidity;
- transfer outside approved partner flows.

## Permitted Phase 3 work

- partner discovery and due diligence;
- data contracts for positions and transfer eligibility;
- read-only investor portfolio status supplied by partner;
- controlled issuer repurchase or transfer-request workflow if partner and counsel approve;
- Phase 4 architecture decision record.
