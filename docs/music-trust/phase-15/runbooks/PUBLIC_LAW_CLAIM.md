# Runbook: Public-Law Claim Stop

If UI/API/comms imply IO, treaty, privilege, immunity, diplomatic, member-state, or UN status without effective instruments:

1. Admin ops → `public_law_claim_stop` and `organization_freeze`.
2. Disable public registry / readiness public surfaces.
3. Publish correcting notice (no endorsement language).
4. Preserve audit trail; open oversight case stub.
5. Do not re-enable until counsel + dual-control approval package.
